### 1. Panduan Operasional Pasien (Pemesanan Obat Online)

Langkah-langkah berikut memandu pasien dari proses pendaftaran hingga penyelesaian pemesanan obat secara daring.

#### 1.1 Langkah 1: Registrasi Akun Baru
1.  Buka situs web e-pharmacy Klinik Makmur Jaya di browser Anda.
2.  Klik tombol **Daftar** di pojok kanan atas halaman.
3.  Isi formulir pendaftaran dengan memasukkan nama lengkap, alamat email yang valid, serta kata sandi minimal 8 karakter yang kuat.
4.  Klik tombol **Daftar** untuk memproses pembuatan akun.

#### 1.2 Langkah 2: Menjelajahi Katalog Obat
1.  Setelah berhasil masuk, Anda akan diarahkan ke halaman **Katalog Obat**.
2.  Gunakan kolom pencarian di bagian atas untuk mengetik nama obat (misal: "Paracetamol").
3.  Gunakan filter drop-down kategori jika Anda hanya ingin menampilkan obat kategori tertentu (misal: "Obat Bebas", "Obat Resep", "Suplemen").
4.  Anda juga dapat mengurutkan produk berdasarkan harga terendah (**Termurah**) atau harga tertinggi (**Termahal**).
5.  Klik tombol **Detail** di kartu obat untuk melihat info komposisi, efek samping, dosis penggunaan, dan ketersediaan stok fisik secara real-time.

#### 1.3 Langkah 3: Mengelola Keranjang Belanja
1.  Di halaman detail obat, tentukan jumlah kuantitas yang ingin dibeli, lalu klik **Tambah ke Keranjang**.
2.  Anda akan diarahkan ke halaman **Keranjang Belanja**.
3.  Di halaman ini, Anda dapat memperbarui jumlah pesanan atau menghapus obat yang batal dibeli.
4.  Total harga belanjaan Anda akan otomatis dihitung di bagian kanan halaman.

#### 1.4 Langkah 4: Checkout dan Pengunggahan Resep Dokter
1.  Di halaman Keranjang Belanja, klik tombol **Checkout**.
2.  Jika di dalam keranjang Anda terdapat obat keras yang wajib menggunakan resep dokter (ditandai dengan label "Wajib Resep"), sistem akan menampilkan kolom pengunggahan berkas resep.
3.  Klik kolom unggah dan pilih foto resep dokter Anda (format berkas JPG/PNG/PDF, ukuran maksimal 2MB).
4.  Klik tombol **Pesan Sekarang** untuk mengirim pesanan Anda ke sistem klinik.

#### 1.5 Langkah 5: Memantau Status Pemesanan
1.  Masuk ke menu **Transaksi Saya** di bilah navigasi atas.
2.  Di sini, Anda dapat memantau status pesanan Anda secara real-time:
    *   **Menunggu Pembayaran:** Pesanan terkirim dan berkas resep dokter sedang diperiksa oleh Apoteker.
    *   **Diproses:** Resep Anda dinyatakan valid, obat sedang disiapkan di instalasi farmasi.
    *   **Selesai:** Obat siap diambil di klinik atau telah diambil oleh pasien.
    *   **Dibatalkan:** Pesanan ditolak oleh Apoteker (karena resep tidak sesuai/tidak valid).

### 2. FAQ (Frequently Asked Questions) - 10 Pertanyaan Umum

#### 1. Bagaimana cara mendaftar akun baru di aplikasi?
Klik tombol "Daftar" di sudut kanan atas halaman navigasi, kemudian isi data diri dan buat kata sandi yang aman.

#### 2. Apakah saya bisa membeli obat tanpa resep dokter?
Obat yang berkategori "Obat Bebas" dan "Suplemen" dapat dibeli langsung tanpa resep dokter. Namun, untuk "Obat Resep" (seperti antibiotik), Anda wajib mengunggah dokumen resep dokter saat checkout.

#### 3. Jenis dokumen apa yang didukung untuk mengunggah resep dokter?
Sistem mendukung file dengan ekstensi JPG, JPEG, PNG, dan PDF dengan ukuran file maksimum 2 Megabyte (MB).

#### 4. Bagaimana cara pembayaran pesanan dilakukan?
Saat ini, pembayaran diproses secara tunai atau debit langsung saat Anda mengambil obat di apotek klinik Makmur Jaya (Offline Payment), atau melalui petunjuk transfer bank yang tertera pada lembar tagihan (invoice).

#### 5. Mengapa status transaksi saya "Dibatalkan"?
Transaksi dibatalkan biasanya terjadi jika berkas resep dokter yang diunggah tidak jelas (buram), telah kadaluarsa, atau obat yang dipesan tidak sesuai dengan isi resep dokter.

#### 6. Di mana saya dapat mengambil obat yang telah saya pesan online?
Obat yang telah dikonfirmasi dan berstatus "Selesai" dapat diambil di loket penyerahan obat Apotek Klinik Makmur Jaya dengan menunjukkan nomor invoice Anda.

#### 7. Apakah stok obat di katalog selalu akurat?
Ya, sistem kami menggunakan integrasi real-time yang memotong stok batch fisik secara otomatis berdasarkan tanggal kadaluarsa (FIFO) saat pesanan diproses.

#### 8. Bagaimana cara mengubah kuantitas obat dalam pesanan saya?
Anda hanya dapat mengubah jumlah obat saat masih berada di halaman "Keranjang Belanja". Apabila transaksi sudah di-checkout, pesanan tidak dapat diubah kembali.

#### 9. Apakah saya bisa membatalkan pesanan yang salah beli?
Pembatalan pesanan secara mandiri hanya dapat dilakukan apabila status transaksi masih berada dalam status "Menunggu Pembayaran" melalui halaman Transaksi Saya.

#### 10. Ke mana saya harus menghubungi jika terjadi kendala pembayaran atau sistem?
Anda dapat menghubungi layanan bantuan klinik Makmur Jaya melalui nomor telepon yang tertera pada bagian bawah halaman web atau mengunjungi loket kasir utama klinik.

### 3. Troubleshooting (Panduan Mengatasi Masalah Umum)

*   **Masalah: Muncul pesan error "Format file tidak valid" saat mengunggah resep.**
    *   *Penyebab:* File yang diunggah bukan berformat gambar atau PDF, atau file tersebut memiliki ukuran lebih besar dari 2MB.
    *   *Solusi:* Kompres ukuran file gambar Anda terlebih dahulu, atau ubah formatnya menjadi format JPG/PNG standar sebelum diunggah kembali.
*   **Masalah: Keranjang Belanja tidak merespon saat diklik "Tambah ke Keranjang".**
    *   *Penyebab:* Sesi login Anda telah habis masa berlakunya (session timeout).
    *   *Solusi:* Muat ulang (*refresh*) halaman web Anda, lakukan masuk (*login*) kembali ke akun Pasien Anda, kemudian coba tambahkan kembali obat ke keranjang.

### 4. Dokumentasi API (Application Programming Interface)

Untuk memfasilitasi integrasi dengan sistem eksternal, Klinik Makmur Jaya menyediakan endpoint API publik berikut:

#### 4.1 Endpoint: Get Katalog Obat
*   **URL:** `/api/obat`
*   **Method:** `GET`
*   **Format Respons:** JSON
*   **Contoh Respons Sukses (HTTP 200):**
    ```json
    {
      "status": "success",
      "count": 20,
      "data": [
        {
          "id": 1,
          "name": "Amoxicillin 500mg",
          "kategori": "Obat Resep",
          "price": 4500.00,
          "requires_prescription": true,
          "total_stock": 120,
          "composition": "Amoxicillin trihydrate 574mg setara Amoxicillin 500mg",
          "dose": "3 x 1 kapsul/hari (setiap 8 jam)"
        }
      ]
    }
    ```

#### 4.2 Endpoint: Cek Stok Kritis & Kadaluarsa
*   **URL:** `/api/cek-stok-kritis`
*   **Method:** `GET`
*   **Format Respons:** JSON
*   **Contoh Respons Sukses (HTTP 200):**
    ```json
    {
      "kritis": [
        {
          "id": 1,
          "name": "Amoxicillin 500mg",
          "stok": 4
        }
      ],
      "hampir_kadaluarsa": [
        {
          "batch_number": "BTH-AMX-2026",
          "name": "Amoxicillin 500mg",
          "expiration_date": "15/07/2026"
        }
      ]
    }
    ```
